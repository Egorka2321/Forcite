# Город в 5 мирах

Онлайн-игра для форсайт-сессии «Сценарии развития территории и устойчивые решения». Участники играют с телефонов, ведущий управляет с ноутбука, на проекторе идёт общий экран.

Сайт лежит на **GitHub Pages**. Синхронизацию между телефонами делает **Google Таблица со скриптом (Apps Script)**: телефоны опрашивают её раз в 1,5–2 секунды. У GitHub Pages нет своего сервера, поэтому без такой связки онлайн-игра невозможна.

## Что внутри

```
docs/            сайт (публикуется через GitHub Pages)
  index.html
  config.js      ← сюда вставляется адрес скрипта
  assets/        код, стили, шрифты, QR-генератор (без внешних CDN)
gas/Code.gs      сервер игры для Google Apps Script
test/            локальная эмуляция сервера и автотест (для запуска не нужны)
```

## Запуск (≈10 минут)

### 1. Сервер в Google Таблице
1. Создайте новую Google Таблицу (например, «Форсайт — сервер»).
2. **Расширения → Apps Script**. Удалите всё в `Code.gs` и вставьте содержимое файла `gas/Code.gs`.
3. В начале файла поменяйте `HOST_PIN = '2040'` на свой PIN.
4. Выберите функцию `setup` и нажмите **Выполнить**. Разрешите доступ к таблице: «Дополнительные настройки» → «Перейти на страницу…».
5. **Развернуть → Новое развертывание → тип «Веб-приложение»**:
   - Выполнять от имени: **Я**
   - У кого есть доступ: **Все**
6. Скопируйте URL, который заканчивается на `/exec`.

> Если меняете `Code.gs` позже: **Развернуть → Управление развертываниями → ✏️ → Версия: новая**. Иначе будет работать старая версия.

### 2. Сайт на GitHub
1. Создайте публичный репозиторий и загрузите в него все файлы (Add file → Upload files).
2. В `docs/config.js` вставьте URL из шага 1.6 в `API_URL`.
3. **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

### 3. Ссылки на игру
| Кто | Ссылка |
|---|---|
| Игроки | `https://<логин>.github.io/<репозиторий>/` (QR показывается на проекторе) |
| Проектор | тот же адрес + `#screen` |
| Ведущий | тот же адрес + `#host` (нужен PIN) |
| Кураторы | тот же адрес + `#curator` (нужен PIN) |

## Ход игры

| Этап | Что делают | Время |
|---|---|---|
| Сбор | Сканируют QR, вводят имя, ждут старта | 3 мин |
| Команды | Выбирают команду сами (до 4 человек) или ведущий раздаёт кнопкой | 2 мин |
| Миры | Каждая команда получает свой сценарий (A–E), придумывает ему название и описывает последствия для жителей, бизнеса и власти. На проекторе собирается сценарная матрица 2×2 с центром | 8 мин |
| Карта | Команда ставит 5 из 15 проектов на карту города и обосновывает выбор | 10 мин |
| Наложение | Пять карт складываются в одну. Проекты, которые выбрали 3+ команды, отмечаются как кандидаты в устойчивые решения | 4 мин |
| Аукцион | У каждой команды 100 монет. Ставки закрытые, по 30–40 с на лот; выигрывает самая высокая. Остаток монет сгорает | 10 мин |
| Судьба | Колесо выбирает, какой мир наступил. Сервер считает очки по скрытой таблице «проект × мир» | 3 мин |
| Шок | Ведущий вытягивает карту-событие, очки пересчитываются, команды пишут, что изменили бы | 4 мин |
| Итоги | Две награды: лучший результат в наступившем мире и самая устойчивая стратегия (лучший результат в худшем из миров) | 5 мин |

**Ведущий** может откатываться на любой этап, вручную менять команды, удалять игроков, отменять лот или его результат, назначать мир вместо случайного.
**Кураторы** с телефона ставят каждому участнику баллы по 4 критериям (3 + 3 + 2 + 2 = 10). На этапе «Итоги» ведущий выгружает оценки в лист «Оценки» Google Таблицы или скачивает CSV.

## Содержание
Город, миры, проекты, карты-шоки — в `docs/assets/content.js`. Таблица отдачи проектов в каждом мире и эффекты шоков — в `gas/Code.gs` (только на сервере, чтобы игроки не подсмотрели её в коде страницы). Все данные учебные, город вымышленный.

## Перед занятием обязательно
- **Репетиция с командой (7 телефонов, 5 минут).** Пройдите все этапы. Затем на пульте: «Сброс игры → Полный сброс».
- **Проверьте связь в аудитории**: откройте сайт с Wi-Fi ВШЭ и с мобильного интернета. Сайт и Google-скрипт должны открываться.
- Если появляется ошибка «Сервер занят», увеличьте `POLL_PLAYER_MS` в `docs/config.js` до 3000.

## Локальный тест (необязательно)

```
npm i playwright
node test/mock-server.js      # запускает настоящий Code.gs в эмуляции Google
node test/e2e.js              # 20 игроков + ведущий + проектор + куратор, вся игра
```
